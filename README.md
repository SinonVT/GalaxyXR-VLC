# GalaxyXR-VLC

A modified version of **VLC for Android** with a **Back button for hand tracking**, designed for the **Samsung Galaxy XR**.

## Features

* Adds an on-screen **Back button** that can be used with hand tracking
* Designed for the Samsung Galaxy XR
* Based on VLC for Android 3.7.2 Beta 3
* ARM64 (`arm64-v8a`) build available for Galaxy XR

## Download

### Samsung Galaxy XR

Download the **ARM64** APK:

**[VLC-Android-3.7.2-Beta-3-arm64-v8a.apk](https://github.com/SinonVT/GalaxyXR-VLC/releases/latest/download/VLC-Android-3.7.2-Beta-3-arm64-v8a.apk)**


> **Note:** Galaxy XR uses a 64-bit ARM architecture, so the `arm64-v8a` APK is the recommended build.

## Installation

1. Download the `arm64-v8a` APK from the Releases page.
2. Install the APK on your Galaxy XR.
3. Open VLC.
4. Use the added Back button with hand tracking to navigate back.

## Other Builds

The release also contains builds for other Android architectures:

* `arm64-v8a` — **Galaxy XR / 64-bit ARM**
* `armeabi-v7a` — 32-bit ARM
* `x86` — 32-bit x86
* `x86_64` — 64-bit x86
* `debug-all` — Debug build containing multiple architectures

For Galaxy XR, **use `arm64-v8a`**.
